# 国庆印尼旅游 · 云端协作版

搭子扫码进来，一起编辑行程、清单、预算；模块和字段本身也能自己加。
没有账号系统 —— 一条带密钥的链接就是入场券。

- 前端：`public/`（原生 JS，无构建步骤），由 Cloudflare 静态资源直接分发
- 接口：`src/api.js`，入口 `worker.js`（Cloudflare Worker）
- 数据库：Cloudflare D1，建表脚本 `schema.sql`
- 二维码：`public/qr.js`，本地生成，不调任何第三方二维码服务

**页面运行时零外部请求** —— 不加载字体、地图、统计、CDN，只跟自己的 `/api` 说话。
这是为了在大陆网络下能稳定打开。

## 一次性部署（约 20 分钟）

### 1. 买域名

Cloudflare 控制台 → **Domain Registration** → **Register Domain**。
`.com` 约 $10.44/年，按成本价，续费同价。需要 Visa/Mastercard 或 PayPal。

> 免费的 `xxx.pages.dev` 在大陆访问不稳定，**必须自备域名**。
> 服务器在 Cloudflare（境外），不需要 ICP 备案。

### 2. 建数据库

Cloudflare 控制台 → **Storage & Databases → D1** → **Create**，
名字填 `guoqing-indonesia`。

### 3. 部署

```bash
cd cloud && ./deploy.sh
```

数据库绑定写在 `wrangler.toml` 里，不用在控制台配 —— 而且**只要这个文件存在，
控制台里配的绑定就会被忽略**，别在两处各配一份。

想接 GitHub 自动部署：Worker → Settings → Builds → Connect，
根目录填 `cloud`，构建命令**留空**，部署命令 `npx wrangler deploy`。

### 4. 建表

在本机仓库目录下跑一次（`--remote` 是打到线上库，不是本地）：

```bash
npx wrangler d1 execute guoqing-indonesia --remote --file cloud/schema.sql
```

### 5. 绑定域名

项目 **Custom domains → Set up a custom domain**，填你买的域名。
证书几分钟内自动签发。

### 6. 验收（这一步不能省）

用**手机蜂窝网络**（不是 Wi-Fi）打开域名，确认：

1. 页面能打开
2. 建一个小组，二维码能显示
3. 把链接发到微信里，**在微信内置浏览器里点开**能正常加载
4. 换一台手机扫码，能填名字进组，改的内容两边都看得到

四条都过了再把二维码发给搭子。

## 本地开发

```bash
cd cloud && npx wrangler dev --port 8788 --persist-to .wrangler/state
```

首次要给本地库建表 —— miniflare 的库文件在
`.wrangler/state/v3/d1/miniflare-D1DatabaseObject/*.sqlite`，
用 sqlite3 把 `schema.sql` 灌进去即可（`wrangler d1 execute --local` 走的是另一个实例，对不上）。

改完代码刷新页面就行，没有构建步骤。

## 权限模型

**没有账号，但每个人有自己的钥匙。** 建组的人是组长。

| 角色 | 能做什么 |
|---|---|
| 组长 | 一切：管成员、设角色、锁模块、换邀请链接、开关入组审批、改模块结构、清空回收站 |
| 可编辑 | 改未锁定模块里的内容；改自己的私人记录 |
| 只读 | 只能看 |

- **邀请链接**只带邀请码，不带钥匙。扫码填名字后服务器才给这台设备发一把钥匙（40 位随机，服务器只存哈希）
- **移除成员** = 作废他所有钥匙，当场失效，拿旧链接也进不来。移除后建议换一条新链接
- **换邀请链接**：旧二维码立刻作废，已在组里的人不受影响
- **入组审批**（开关，默认关）：开了之后新人扫码先进「等待确认」，组长点同意才进
- **锁模块**：⚙ 里勾「只有组长能改」。新建的组默认锁「路线计划」；「航班」不锁，因为每个人要填自己的
- **改动记录**：每条记录改动前自动快照（最多留 20 版），编辑弹窗里「改动记录」可一键恢复到任何一版。这是对付误改和捣乱的主要手段 —— 改坏了随手撤销，比事前审批实用
- **换设备**：小组弹窗 →「换设备」→ 8 位数字码（10 分钟有效、一次性）。新设备输入后拿到自己的钥匙，两台设备都算同一个人

**仍然不适合放**：证件号、银行卡、护照照片。页面底部有提示。

### 从旧版（一把万能钥匙）迁移

线上库跑 `migrate-b.sql`（只加列加表），然后给每个旧组：设 `owner_id`、发 `invite_code`、把 `legacy_until` 设到 7 天后。
过渡期内，已有成员用旧链接打开会自动换发个人钥匙（每台设备一把）；**组长身份不走这条路**，
要在 `transfers` 表里插一条组长的设置码，通过 `#t=<码>` 链接单独交给组长激活 —— 否则拿到旧链接的人也能当组长。
组长换一次邀请链接，过渡期就提前结束。

## 冲突处理

每条记录带版本号。两个人同时改同一条时，后保存的会收到 409，
弹窗保持打开、**保留你已经填的内容**，并提示队友刚改过；确认后再点一次保存就覆盖成你的版本。

前台每 15 秒自动同步一次；切回前台或网络恢复时立刻同步。编辑弹窗打开时不打扰。

## 结构

```
cloud/
├── schema.sql                 建表（groups / members / tokens / transfers / modules / entries / history）
├── migrate-b.sql              旧库升级到权限模型：只加列加表
├── wrangler.toml              Worker 配置 + D1 绑定
├── worker.js                  入口：/api/travel 交给 src/api.js，其余走静态资源
├── src/
│   ├── api.js                 全部接口：建组/加入/模块增删改/记录增删改/回收站
│   └── seed.js                建组时铺的初始攻略数据
└── public/
    ├── index.html             页面骨架
    ├── app.js                 主应用，按云端返回的模块定义动态渲染
    ├── qr.js                  二维码生成（字节模式，纠错 M，版本 1–10）
    ├── seed.js                未建组时只读公开攻略用的数据副本
    └── style.css
```

模块（页签）和字段定义都存在数据库里，内置模块和自建模块走同一套逻辑 ——
所以内置模块也能改名、换图标、加字段、隐藏。内置模块不能删，只能隐藏。
